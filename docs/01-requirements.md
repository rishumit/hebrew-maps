# מסמך דרישות – תוכנת מפות ישראל
**גרסה:** 1.0  
**תאריך:** אוקטובר 2026  
**סטטוס:** טיוטה לאישור

---

## 1. מטרת המוצר

בניית אפליקציית מפות ישראל ברמה מקצועית, המציגה מפת ישראל אינטראקטיבית עם מאגר נקודות עניין (POI) עשיר, יכולות חיפוש מלאות, וחוויית משתמש ברמת Google Maps.

---

## 2. יכולות ליבה נדרשות

### 2.1 תצוגת מפה
- הצגת מפה אינטראקטיבית של ישראל ואזוריה
- תמיכה בזום בין רמת מדינה ורמת רחוב
- שכבות מפה: כביש, לוויין, טופוגרפי, הליכה
- ניווט חלק (pan/zoom) עם מגע ועכבר
- תמיכה מלאה בממשק RTL בעברית
- כיוון הפה לכיוון עברי בכל רכיב UI

### 2.2 נקודות עניין (POI)
- הצגת סמנים (markers) על המפה לפי קטגוריה
- קליק על סמן → כרטיס מידע מפורט
- קיבוץ סמנים (clustering) בזום נמוך
- סינון POI לפי קטגוריה / תגיות
- מידע בכרטיס: שם, תיאור, כתובת, טלפון, שעות פעילות, תמונות, דירוג

### 2.3 חיפוש
- חיפוש טקסטואלי חופשי בעברית ובאנגלית
- תיקון שגיאות כתיב ו-fuzzy search
- השלמה אוטומטית (autocomplete) תוך כדי הקלדה
- חיפוש לפי:
  - עיר / שכונה / ישוב
  - רחוב + מספר בית
  - שם אתר / עסק / מוסד
  - קטגוריה (למשל: "מסעדות ליד תל אביב")
- תוצאות ממוינות לפי רלוונטיות ומרחק

### 2.4 ניווט ומרחק
- חישוב מסלול בין שתי נקודות (הולך רגל / אופניים / רכב)
- הצגת זמן נסיעה ומרחק
- הדרכה פנייה-פנייה (turn-by-turn) – שלב 2

## 3. מאגר נקודות עניין (POI) – דרישות

### 3.1 קטגוריות נדרשות
| קטגוריה | דוגמאות |
|---------|---------|
| אתרי תיירות | מוזיאונים, עתיקות, גנים לאומיים |
| דת ועדה | בתי כנסת, כנסיות, מסגדים |
| מסחר ושירות | מרכזי קניות, סופרמרקטים, בנקים |
| מזון ואירוח | מסעדות, בתי קפה, מלונות |
| חינוך | אוניברסיטאות, בתי ספר, ספריות |
| בריאות | בתי חולים, קופות חולים, בתי מרקחת |
| תחבורה | תחנות רכבת, תחנות אוטובוס, חניונים |
| פנאי וספורט | גנים, חופים, מגרשי ספורט |
| שירותי ממשל | עיריות, דואר, משטרה |
| ערים וישובים | כל יישוב בישראל עם גיאוגרף מדויק |

### 3.2 שדות מינימום לכל POI
```json
{
  "id": "unique-id",
  "name_he": "שם בעברית",
  "name_en": "English name",
  "category": "tourism",
  "sub_category": "museum",
  "lat": 32.0853,
  "lon": 34.7818,
  "address": "רחוב דיזנגוף 1",
  "city": "תל אביב",
  "phone": "03-1234567",
  "website": "https://example.com",
  "opening_hours": "09:00-17:00",
  "description": "תיאור קצר",
  "images": ["url1", "url2"],
  "tags": ["tag1", "tag2"],
  "rating": 4.5
}
```

### 3.3 גודל מאגר יעד
- **ישובים:** ~1,200 (כל הישובים בישראל)
- **רחובות:** ~200,000 (כל הרחובות לפי עיר)
- **POI נקודות עניין:** לפחות 50,000 נקודות

## 4. מקורות מידע מומלצים לאיסוף נתונים

### 4.1 מקורות פתוחים (Open Data) – עדיפות ראשונה
| מקור | סוג מידע | פורמט | הערות |
|------|---------|-------|-------|
| **OpenStreetMap (OSM)** | מפה + POI + כבישים + כל מה שיש | PBF / GeoJSON | הכי עשיר, בחינם, רישיון ODbL |
| **מפת ישראל הפתוחה** (gov.il/data) | ישובים, רחובות, גבולות | GeoJSON / Shapefile | נתוני ממשלה רשמיים |
| **Wikidata** | אתרי תרבות, מוזיאונים, ערים | SPARQL API | קישור ל-Wikipedia |
| **data.gov.il** | מבנים ציבוריים, בתי ספר, מרפאות | CSV / JSON | נתונים ממשלתיים רשמיים |
| **Overpass API** | שאילתות OSM בזמן אמת | JSON / XML | לדוגמה: כל בתי הקפה בתל אביב |
| **GeoNames** | ישובים בינלאומיים + ישראל | CSV | תמיכה בשפות מרובות |

### 4.2 API מסחריים לשיפור איכות – עדיפות שנייה
| מקור | שימוש | הערות |
|------|-------|-------|
| **Google Places API** | העשרת POI עם שעות, תמונות, דירוג | בתשלום, מוגבל ל-T&C |
| **HERE Maps** | כבישים, ניווט, geocoding | מסחרי, API חינמי מוגבל |
| **Foursquare Places** | עסקים, מסעדות, בידור | גרסת community בחינם |

### 4.3 מקורות ייחודיים לישראל
| מקור | מה ניתן לקבל | כיצד לגשת |
|------|------------|-----------|
| **רשות עתיקות ישראל** | אתרי עתיקות רשמיים | API פתוח / scraping בהיתר |
| **רשות הטבע והגנים** | גנים לאומיים, שמורות | data.gov.il |
| **מאגר הרחובות הלאומי** | כל רחוב בישראל עם geocoding | data.gov.il |
| **לשכה מרכזית לסטטיסטיקה (CBS)** | נתונים דמוגרפיים לישובים | cbs.gov.il |
| **ויקיפדיה בעברית** | תיאורים, תמונות, מידע עשיר | MediaWiki API |

### 4.4 אסטרטגיית איסוף מומלצת

```
שלב א – בסיס מפה:
  └─ הורד Israel.osm.pbf מ-download.geofabrik.de
  └─ עבד עם osm2pgsql לתוך PostgreSQL+PostGIS

שלב ב – ישובים ורחובות:
  └─ data.gov.il → מאגר הרחובות הלאומי (CSV מלא)
  └─ העשר עם GeoNames לקוארדינטות מדויקות

שלב ג – POI עשיר:
  └─ Overpass API → כל קטגוריות OSM בישראל
  └─ Wikidata SPARQL → אתרי תרבות + תמונות
  └─ data.gov.il → מוסדות ציבור (בתי ספר, בתי חולים)

שלב ד – העשרה:
  └─ Wikipedia API → תיאורים קצרים בעברית
  └─ Wikimedia Commons → תמונות ברישיון פתוח
```

## 5. ארכיטקטורה – גבולות בלבד (לא בחירת רכיב)

### 5.1 שכבות מערכת
```
Frontend (ממשק משתמש)
    ↕
API Gateway
    ↕
Backend Services:
  ├─ Map Tiles Service    – הגשת שכבות מפה
  ├─ Search Service       – חיפוש טקסטואלי
  ├─ POI Service          – ניהול נקודות עניין
  └─ Geocoding Service    – כתובת ↔ קואורדינטות
    ↕
Data Layer:
  ├─ Spatial Database     – נתוני מפה + POI
  ├─ Search Index         – אינדקס חיפוש
  └─ Object Storage       – תמונות ומשאבים
```

### 5.2 פרוטוקולים נדרשים
- Map tiles: פרוטוקול XYZ / MVT (vector tiles)
- Geocoding: GeoJSON סטנדרטי
- POI API: REST / GraphQL
- חיפוש: full-text עם תמיכה בעברית (ניתוח מורפולוגי)

## 7. דרישות UX / נגישות

- ממשק מלא בעברית, RTL נכון בכל רכיב
- גופן מותאם לעברית (נקי, קריא)
- תמיכה במובייל (responsive / PWA)
- ניגודיות WCAG AA
- תמיכה בקורא מסך לנגישות
- Dark mode אופציונלי
