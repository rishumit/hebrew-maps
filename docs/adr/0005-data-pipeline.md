# ADR 0005 – צינור נתונים: osmium + Python, העשרה "best effort"

**סטטוס:** התקבל · אוקטובר 2026

## החלטה
1. **osmium-tool** מסנן את קובץ ה-PBF ומייצא GeoJSON-seq. הוא אחראי להרכבת פוליגונים ולמיקום צמתים, וזה החלק הכבד, שכתוב ב-C++.
2. **Python** ממיין את הישויות לקטגוריות אחידות (`hmaps/core/categories.py`: כ-70 תת-קטגוריות בעברית), משייך עיר לכל ישות (תגית, ואחרת point-in-polygon וקטורי ב-numpy מול גבולות שיפוט, ואחרת היישוב הקרוב), מאחד כפילויות (צומת ופוליגון של אותו מקום), ממזג קטעי רחוב לרחובות, ומפענח שעות פתיחה.
3. **העשרה:** רשימת היישובים והרחובות הרשמית מ-data.gov.il (סמל יישוב, שם באנגלית, נפה, וכיסוי רחובות), תמונות ותיאורים מ-Wikidata ומוויקיפדיה. כל מקור חיצוני הוא "best effort": כשל ברשת נרשם בלוג, והבנייה ממשיכה.
4. **בקרת איכות:** דוח (`/reports`) עם מדדי ה-KPI ממסמך 03 §9 ובדיקות תקינות.

## הערות
- רשות העתיקות ורשות הטבע והגנים: לא נמצא API פתוח ויציב. אתרי עתיקות, גנים לאומיים ושמורות נלקחים מתגיות OSM (`historic=*`, ‏`boundary=national_park`, ‏`leisure=nature_reserve`).
- Google Places ודומיו לא נעשה בהם שימוש, בהתאם לעיקרון "נתונים פתוחים תחילה" ובגלל תנאי השימוש שלהם. לכן אין "דירוג כוכבים": השדה קיים ב-API וערכו null.
