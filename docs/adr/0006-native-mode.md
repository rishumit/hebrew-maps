# ADR 0006 – הפעלה בלי Docker

**סטטוס:** התקבל · אוקטובר 2026

## הקשר
בחלק מהמחשבים אי אפשר להתקין את Docker Desktop: חסרות הרשאות מנהל, הווירטואליזציה כבויה, או ש-WSL לא נתמך. המערכת צריכה לעבוד גם במחשבים כאלה.

## החלטה
- **Python** מורד ומנוהל בתוך תיקיית הפרויקט עם `uv` (קובץ exe יחיד), בלי התקנה במערכת ובלי הרשאות מנהל.
- **חילוץ OSM** נעשה עם pyosmium (חבילת pip, כולל הרכבת פוליגונים), במקום osmium-tool. שני המנועים מזינים את אותו `Builder`.
- **ניווט:** מנוע פנימי (`hmaps/route`): גרף דרכים שנבנה באותו מעבר על הנתונים, ‏A* עם יוריסטיקת זמן, הצמדה לנקודה הקרובה על קטע הדרך, וזיהוי פניות וכיכרות. התשובות בפורמט OSRM, ולכן גם ההוראות בעברית משותפות. ביצועים: מסלול עירוני ב-‎~10ms, ומסלול ארוך על גרף של 160 אלף צמתים ב-‎~0.5 שניות.
- **מפת בסיס:** Planetiler עם Java 21 נייד (Temurin), שמורד לתיקיית `tools-bin`. אם זה נכשל, המפה עובדת עם מפת הגיבוי.
- **החלפת נתונים ב-Windows:** קובץ פתוח לא ניתן להחלפה, ולכן כל בנייה נכתבת לקובץ חדש עם חותמת זמן (`maps-<ts>.db`, ‏`israel-<ts>.mbtiles`), וקובץ מצביע (`maps.current`) קובע איזה קובץ פעיל. השרת עובר לקובץ החדש לבד. השיטה פועלת גם ב-Docker.

## השלכות
- בגרסה בלי Docker אין מסלולים חלופיים (רק המסלול המהיר), ואין הגבלת זיכרון לתהליכים.
- השרת מאזין רק ל-localhost כברירת מחדל. גישה מהרשת: `HMAPS_HOST=0.0.0.0`.
- המתקין (`installer/`) מציג את המפה בחלון שולחן עבודה (Tauri) במקום בדפדפן, ו-`hebrew-maps.exe` מקבל `--no-browser`/`--port`. ראו [ADR 0009](0009-desktop-tauri.md).
