# עירובין ומקומות בתנ״ך
date: 2026-11-05

- עירובין ותחום שבת: בתפריט ← "עירובין ותחום שבת" – 38 ערים עם האחראים לכל אזור, טלפונים, מפות העירוב ומאמרי תחום שבת, באדיבות מוקד העירוב.
- בתי חולים בשבת: רב בית החולים, שירותי הדת, העירוב במתחם ותחום השבת, ממקורות רשמיים. וגם רשימת עירובין בחו"ל וחוברות.
- שכבת "קווי עירוב (בקירוב)": קווי העירוב המשורטטים לפי מפות המוקד; לחיצה על קו מציגה את האחראי ואת המפה המקורית. לפני שבת יש לוודא מול האחראי המקומי.
- מקומות בתנ״ך: בתפריט ← "מקומות בתנ״ך" – 336 ערים, הרים, נהרות, ארצות ותחנות מסעות מהתנ״ך ומדברי חז״ל, עם שיטות הזיהוי, הפסוקים ודברי חז״ל (מתוך "מדריך מקומות בתנ״ך" של  מפתחי אוצריא).
- שכבת "מקומות בתנ״ך" במפה: נקודה לכל שיטת זיהוי, בצבע לפי הסוג ובמילוי לפי רמת הוודאות.
- "מה יש כאן?" (לחיצה ימנית על המפה): האם הנקודה בתוך קו עירוב, מה ידוע על העירוב בעיר, ואילו מקומות מהתנ״ך נמצאים בסביבה.
