# פתיחה מהירה יותר ופקדי מפה חדשים
date: 2026-11-06

- פתיחה מהירה יותר של האפליקציה: שרת המפות עולה מהר יותר, והמפה מוצגת מיד כשהוא מוכן.
- מסך טעינה חדש, ביום ובלילה, שנשאר עד שהמפה מצוירת – בלי הבזק של מסך לבן או מפה ריקה.
- כפתור "סוג מפה" חדש בצד המפה, עם תמונה של סוג המפה הנוכחי (רגילה, טבע וטיולים, טופוגרפית, לילה, תצלומי לוויין).
- כפתור "שכבות" מציג עכשיו רק את השכבות.
- כפתור יום/לילה: לחיצה אחת מחליפה בין מצב יום למצב לילה.
