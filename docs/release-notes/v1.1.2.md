# מפות ישראל v1.1.2

- מתקין Windows כולל מפה ונקודות עניין, גרף ניווט, מפת בסיס, תחבורה ציבורית וזמני תפילות.
- עדכון תוכנה משתמש במתקין קטן שאינו מוריד מחדש את נתוני המפה.
- עדכונים למחשב ללא אינטרנט זמינים גם כקובץ נפרד לכל רכיב.
- בחלונית השכבות, תצלומי לוויין הם סוג מפה, והורדותיהם מופיעות רק כאשר סוג זה נבחר.
