# היסטוריה, מדידת מרחק ושיפורים
date: 2026-11-10

- היסטוריה: לשוניות נפרדות לחיפושים אחרונים, יעדים שביקרתם ומסלולים שתכננתם, עם שמירה אוטומטית. קיצור מקלדת Ctrl+H.
- כלי מדידת מרחק: מדידה של מרחקים על המפה.
- כפתור סוג מפה עבר לטור נפרד ליד כפתורי ההגדלה.
- תיקוני אבטחה: מטמון אריחים, בדיקת DNS rebinding, ו-Esc סוגר דיאלוגים גם כשהמיקוד במקום אחר.
- תיקון: מצב יום/לילה מתעדכן נכון בכל הלשוניות.
