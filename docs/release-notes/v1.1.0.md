# עדכון התוכנה מתוך התוכנה, ועדכונים חלקיים
date: 2026-10-26

- עדכון התוכנה עצמה מדף "עדכונים": התקנה שקטה, והתוכנה נפתחת מחדש בגרסה החדשה. הנתונים שבמחשב נשמרים.
- עדכון חלקי של הנתונים: יורד רק מה שהשתנה – תמונות שנוספו, או תיקון קטן למאגר המקומות ולמפת הבסיס – במקום החבילה המלאה.
- לשוניות בעיצוב כרום: צורה מעוגלת, מפרידים, סמל לפי תוכן הלשונית, והתכווצות כשיש הרבה לשוניות.
- מקום שנבחר ותוצאות חיפוש מסומנים בצבע ובסמל של הקטגוריה שלהם.
- אתרי רשות הטבע והגנים מוצגים במפה עם הסמל הרשמי של הרשות.
