# תיקוני באגים
date: 2026-11-04

- מגע צביטה לשינוי גודל המפה עבד רק באזור שמעל לחלונית המידע התחתונה; כעת אצבעות הצביטה עוברות דרך הרקע של החלונית ישירות למפה.
- הדפסת מפה מתפריט ימני (לחיצה ארוכה) הציגה "המפה עדיין נטענת" מיד לאחר הלחיצה; כעת ההדפסה ממתינה אוטומטית עד שהמפה מסיימת להתמקם.
- כאשר שכבת מפת העולם מופעלת, תצלומי הלוויין (אונליין ואופליין) לא הוצגו; שכבות ה-Natural Earth של מפת העולם לא נכללו ברשימת השכבות הנסתרות מתחת לתצלום.
