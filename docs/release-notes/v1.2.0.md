# מועדפים, אפשרויות מסלול ומפת העולם
date: 2026-11-03

- מקומות מועדפים: כפתור ★ "שמירה" בכרטיס של כל מקום ובתחנות תחבורה ציבורית, עם שם משלכם ("הבית", "סבתא"). המועדפים מופיעים ראשונים בחיפוש ובתכנון מסלול.
- שמירת מסלולים וחיפושים: בתפריט ← "המועדפים והשמורים שלי", עם ייצוא וייבוא לקובץ. הכול נשמר רק במחשב, בלי חשבון.
- אפשרויות מסלול: הימנעות מכבישי אגרה, כבישים מהירים, דרכי עפר ארוכות, צמתים מאתגרים ושטחי A/B של הרשות הפלסטינית (בקירוב).
- תחבורה ציבורית: מקטעי ההליכה מסומנים לאורך הרחובות ולא בקו ישר, ולכל אפשרות נסיעה מוצג מחיר משוער לפי רב-קו.
- בחירת תיקיית נתונים: בתפריט ← "הגדרות ותיקיית נתונים" אפשר להעביר את נתוני המפה לכונן אחר, עם העתקת הנתונים הקיימים.
- מפת העולם: בהתרחקות מוצג כל הגלובוס בפירוט נמוך, עם שמות בעברית.
- שכבות: חלון השכבות מאפשר להציג ולהסתיר בנפרד נקודות עניין, שבילים, שמורות טבע, שמות, מבנים, קווי גובה והצללת תבליט.
- הורדת תצלומי אוויר לשימוש בלי אינטרנט עברה לחלונית העדכונים.
- בלחיצה ימנית על המפה: שמירה במועדפים, הדפסת המפה והדפסת המסלול.
