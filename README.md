# מפות בעברית

מערכת מפות אינטראקטיבית של ישראל, עברית מלאה מימין לשמאל, שרצה כולה על המחשב שלכם מנתונים פתוחים.
המערכת כוללת חיפוש חכם בעברית, נקודות עניין, כתובות, ניווט ברכב, ברגל ובאופניים, מצב לילה, ותמיכה מלאה בנגישות ובמובייל.

## התקנה ב-Windows – בלי Docker (הדרך הפשוטה)

1. **לחצו פעמיים על `setup-windows.cmd`** בתיקייה זו. לא צריך להתקין שום דבר מראש, וגם לא צריך הרשאות מנהל.
2. **הדפדפן ייפתח לבד** בכתובת http://localhost:8080. בהתחלה יוצגו נתוני הדגמה, והמפה תשתדרג לבד כשהנתונים המלאים יהיו מוכנים.
3. **בפעמים הבאות** לוחצים על קיצור הדרך "מפות בעברית" שנוצר על שולחן העבודה (או על `start-windows.cmd`).

מה ההתקנה עושה:

| שלב | מה נעשה | זמן משוער |
|-----|---------|-----------|
| 1 | הורדת Python לתיקייה פרטית בעזרת `uv` (בלי התקנה במערכת) | 1–3 דקות |
| 2 | הורדת ספריית המפה והגופנים | דקה |
| 3 | הפעלת המפה + יצירת קיצור דרך על שולחן העבודה | מיידי |
| 4 | הורדת מפת ישראל מ-OpenStreetMap (כ-150MB) | 1–3 דקות |
| 5 | בניית המקומות, הרחובות, החיפוש **והניווט** | 15–30 דקות |
| 6 | בניית מפת הבסיס המלאה (Java נייד מורד אוטומטית, גם הוא בלי התקנה) | 15–40 דקות |

אם שלב 6 נכשל, המפה ממשיכה לעבוד עם מפת בסיס פשוטה. אפשר לנסות שוב עם `update-windows.cmd`.

בסוף ההתקנה נבנות גם **השכבות הטופוגרפיות** (קווי גובה, הצללה ופרופיל גובה). זה שלב אופציונלי: הורדה חד-פעמית של כ-530MB מ-Copernicus, ‏10–20 דקות, וכ-200MB בדיסק. אם השלב נכשל, כל השאר עובד, ואפשר לנסות שוב עם `build-terrain.cmd`. כדי לדלג עליו: `set HMAPS_SKIP_TERRAIN=1` לפני ההתקנה.

| קובץ | תפקיד |
|------|--------|
| `start-windows.cmd` | הפעלה ופתיחת הדפדפן |
| `stop-windows.cmd` | עצירת השרת |
| `update-online-windows.cmd` | **עדכון הנתונים מהאינטרנט – הדרך המומלצת** (ראו [עדכונים](#עדכונים)); ‏`/schedule` מתזמן אותו לכל שבוע |
| `update-windows.cmd` | בנייה מקומית מחדש של כל הנתונים מהמקורות (למתקדמים, שעה ויותר) |
| `update-transit-windows.cmd` | בנייה מקומית של לוחות הזמנים של התחבורה הציבורית בלבד (למתקדמים, 2–5 דקות) |
| `update-zmanim-windows.cmd` | משיכה מקומית של זמני התפילות מנדרים פלוס (למתקדמים, 10–15 דקות) |
| `build-terrain.cmd` | בנייה (או בנייה מחדש) של קווי הגובה וההצללה |
| `download-satellite.cmd` | הורדת תצלומי אוויר של כל הארץ לשימוש בלי אינטרנט: בוחרים רמה (בסיסי כ-80MB / מפורט כ-1GB / מלא כ-4GB) ומאשרים; ‏`--test` בודק אילו שרתי תצלומים עובדים מהמחשב |

### תצלומי אוויר גם בלי אינטרנט

בכפתור השכבות יש מתג **"תצלום אווירי (אורתופוטו)"**: תצלומי האוויר של מרכז מיפוי ישראל (govmap), עם הכבישים והשמות מעליהם. כשאין גישה ל-govmap (למשל חסימה בסינון) מוצגים תצלומי לוויין Sentinel-2 ‏(EOX, ברזולוציה נמוכה יותר) עד זום 14.
כל אזור שנצפה פעם אחת נשמר במחשב (`data/tiles/satellite*.mbtiles`) ומוצג אחר כך גם בלי אינטרנט. התצלומים של govmap מוגנים בזכויות יוצרים של מרכז מיפוי ישראל – לשימוש אישי בלבד, ולכן הם לא חלק מעדכון הנתונים השבועי וכל אחד מוריד אותם לעצמו. כדי לשמור מראש:

- **מהמפה:** מגיעים לאזור, ובכפתור השכבות לוחצים **"שמירת האזור הנוכחי לשימוש אופליין"**. מוצגים מספר האריחים והגודל המשוער, ואחרי האישור ההורדה רצה ברקע (מהזום הנוכחי ועד 3 רמות פירוט נוספות, עד 30,000 אריחים בפעם).
- **כל הארץ מהמפה:** כפתור השכבות ← **"הורדת תצלומי אוויר לכל הארץ"**, בוחרים רמת פירוט (מוצגים מספר האריחים, הגודל והזמן המשוער) ולוחצים "הורדה". ההורדה רצה ברקע, עם התקדמות וכפתור עצירה; לחיצה חוזרת ממשיכה מאותה נקודה.
- **כל הארץ מהפקודה:** ‏`download-satellite.cmd` שואל איזו רמה:
  - **בסיסי** – זום עד 13: כ-3,000 אריחים, כ-80MB, כ-10 דקות;
  - **מפורט** – זום עד 15 (רחובות ובתים): כ-41,000 אריחים, כ-1GB, כ-2–3 שעות;
  - **מלא** – זום עד 16: כ-160,000 אריחים, כ-4GB, כ-9 שעות (גדול מאוד).

  אפשר לעצור (Ctrl+C) ולהריץ שוב – ההורדה ממשיכה מאיפה שנעצרה. בלי שאלות: `download-satellite.cmd --level detailed -y`. אזור אחד בפירוט גבוה: `download-satellite.cmd --bbox 34.75,32.03,34.83,32.12 --minzoom 12 --maxzoom 17` (‏`--dry-run` מציג רק את ההערכה).
- **לא יורד כלום?** ‏`download-satellite.cmd --test` בודק כל שרת תצלומים ומדפיס מה חזר (תמונה, "אין אריח", דף חסימה של הסינון או שגיאת רשת). אם `cdn.govmap.gov.il` חסום בסינון – אפשר לבקש לפתוח אותו.

כל רמת זום נוספת מכפילה פי 4 את מספר האריחים (בערך 25KB לאריח). רק שטח הארץ נספר – בלי ים ומדינות שכנות. ‏[ADR 0003](docs/adr/0003-basemap.md)

הניווט בגרסה זו פועל במנוע ניווט פנימי (רכב, הליכה ואופניים), ולכן אין צורך בשרת ניווט נפרד.

### אפליקציית שולחן העבודה (חלון במקום דפדפן)

המתקין (`installer\build.ps1`, או מתקין מוכן מה-Releases) כולל את `hebrew-maps-desktop.exe`. זו אפליקציית Tauri שפותחת את המפה **בחלון משלה** ולא בדפדפן:
- השרת מופעל ברקע, ובזמן הטעינה מוצג מסך "טוען את המפה…".
- סגירת החלון עוצרת את השרת. גם אם האפליקציה קורסת, השרת לא נשאר לרוץ ברקע.
- הפעלה כפולה רק מביאה את החלון הפתוח לחזית. גודל החלון ומיקומו נשמרים.
- קישורים חיצוניים, כמו ויקיפדיה, נפתחים בדפדפן הרגיל.
- **לשוניות:** כמה מפות במקביל, כמו בדפדפן. הלשוניות נמצאות בשורת הכותרת של החלון (שורת כותרת משלנו, מימין לשמאל: הסמל והשם מימין, כפתורי מזעור/הגדלה/סגירה משמאל). כותרת הלשונית מתעדכנת לפי מה שבמפה: החיפוש, המקום שנבחר או המסלול ("א ← ב"). הלשוניות הפתוחות נפתחות שוב בהפעלה הבאה.
  קיצורים: ‏Ctrl+T לשונית חדשה, ‏Ctrl+W סגירה (גם לחיצה באמצעי העכבר), ‏Ctrl+Shift+T פתיחה מחדש של לשונית שנסגרה, ‏Ctrl+Tab / ‏Ctrl+Shift+Tab מעבר, ‏Ctrl+1…9 מעבר ללשונית לפי מספר. אפשר לגרור לשונית כדי לשנות את הסדר.

האפליקציה צריכה את WebView2 של Microsoft. הוא מותקן מראש ב-Windows 11 וב-Windows 10 מעודכן. במחשב בלי WebView2, קיצור הדרך פותח את הדפדפן כמו קודם.
גם `start-windows.cmd` משתמש באפליקציה כשהיא בנויה (`src-tauri\target\release`) או מותקנת. אחרת הוא פותח את הדפדפן. כדי לכפות דפדפן: `set HMAPS_BROWSER=1`.
פרטים טכניים: [ADR 0009](docs/adr/0009-desktop-tauri.md) ו-[installer/README.md](installer/README.md).

## עדכונים

הנתונים נבנים מחדש **פעם בשבוע** (ביום חמישי בלילה) ב-GitHub Actions ומתפרסמים כחבילות ב-[GitHub Releases](https://github.com/rishumit/hebrew-maps/releases) של הפרויקט, כך שאין צורך לבנות אותם על המחשב שלכם:

- **מתוך המפה:** תפריט ← **עדכונים**. לכל חבילה מוצגים התאריך המותקן, התאריך הזמין והגודל, ואפשר ללחוץ "עדכן" או "עדכן הכול". סרגל התקדמות מראה את ההורדה, המפה ממשיכה לעבוד בזמן העדכון ועוברת לנתונים החדשים לבד. בדף יש גם הגדרה לבדיקה אוטומטית פעם בשבוע: כשיש עדכון מופיעה הודעה קטנה בתחתית המסך.
- **בלי לפתוח את המפה:** לחיצה כפולה על `update-online-windows.cmd` (או `python -m hmaps update`; ‏`--check` רק בודק, ‏`--component transit` מעדכן חבילה אחת).
- **אוטומטית כל שבוע:** `update-online-windows.cmd /schedule` יוצר משימה מתוזמנת ב-Windows (יום שישי ב-06:10, אחרי פרסום הנתונים). היומן נכתב ל-`data\reports\update-log.txt`.

| חבילה | מה יש בה | תדירות |
|-------|----------|--------|
| מפה ונקודות עניין (`maps`) | המקומות, הרחובות, הכתובות והחיפוש, שבילים, טקסטים מוויקיפדיה וגרף הניווט | שבועית |
| מפת בסיס (`basemap`) | אריחי המפה המלאה (Planetiler) | שבועית |
| נתוני גובה וטופוגרפיה (`terrain`) | קווי גובה, הצללה ופרופיל גובה (Copernicus DEM) | חודשית – כמעט לא משתנה |
| תחבורה ציבורית (`transit`) | לוחות הזמנים של משרד התחבורה (GTFS) | שבועית |
| תמונות ותוכן (`media`) | תמונות האתרים לצפייה ללא אינטרנט | שבועית |
| זמני תפילות (`zmanim`) | זמני התפילות בבתי הכנסת (נדרים פלוס) | שבועית |

כל קובץ נבדק מול ה-SHA-256 שב-`manifest.json` לפני שהוא מותקן, והורדה שנקטעה ממשיכה מהמקום שבו נעצרה. ההתקנה לא מחליפה קובץ פתוח: מאגר חדש נכנס דרך קובץ המצביע `maps.current`, ומפת בסיס חדשה נשמרת בשם חדש. הגרסאות המותקנות נרשמות ב-`data/components.json`. אחרי עדכון של מפת הבסיס או של נתוני הגובה, רעננו את הדף כדי לראות את כל האריחים החדשים.

**רשת מסוננת (נטפרי, רימון וכו'):** ההורדה היא מ-`github.com`, שמפנה ל-`release-assets.githubusercontent.com` (או `objects.githubusercontent.com`). אם העדכון נכשל, בקשו מהסינון לפתוח את הכתובות האלה. תעודת האבטחה של הסינון מתקבלת אוטומטית, ושלמות הקבצים מובטחת בבדיקת ה-SHA-256.

## התקנה עם Docker (חלופה)

1. התקינו Docker Desktop מהכתובת https://www.docker.com/products/docker-desktop/ והפעילו אותו. מומלץ להקצות לו 6GB זיכרון.
2. לחצו פעמיים על `setup.cmd`. לאחר מכן משתמשים ב-`start.cmd`, ‏`stop.cmd` ו-`update-data.cmd`.

בגרסת Docker הניווט רץ על OSRM, ומפת הבסיס נבנית בקונטיינר. ב-Linux/macOS: ‏`./setup.sh` (או `./setup.sh --update`).

## מה יש במערכת

- **מפה** בארבעה סגנונות: רגילה, טבע וטיולים, טופוגרפית (קווי גובה, הצללת תבליט ונקודות גובה) ולילה. מצב בהיר/כהה לממשק, ושמות בעברית לכל מקום.
- **חיפוש בעברית** שמבין:
  - שמות: "מגדל דוד", "הכותל"
  - כתובות: "דיזנגוף 50 תל אביב", "רח' הרצל 12, רחובות", "ירושלים, יפו 97"
  - קטגוריות ומקום: "מסעדות בתל אביב", "בית מרקחת פתוח ליד", "מסעדה כשרה באזור חיפה"
  - קיצורים: ת"א, ב"ש, פ"ת, ביה"ח, שד'
  - שגיאות כתיב: "דיזינגוף", "מגדל דויד"
  - הקלדה במקלדת אנגלית בטעות: sh,bdu; ← דיזנגוף
  - קואורדינטות: ‎32.0853, 34.7818
- **כרטיס מידע** לכל מקום: כתובת, טלפון, אתר, שעות פתיחה כולל "פתוח עכשיו / נסגר ב-…", כשרות, נגישות, תיאור ותמונה מוויקיפדיה, שיתוף והעתקה.
- **ניווט** ברכב, ברגל ובאופניים: מסלולים חלופיים, זמן ומרחק, והוראות פנייה-פנייה בעברית ("בכיכר צאו ביציאה השנייה לרחוב אלנבי"). בהליכה ובאופניים מוצג גם פרופיל גובה עם עלייה וירידה מצטברות.
- **תחבורה ציבורית** (אוטובוס, רכבת, רכבת קלה), גם בלי אינטרנט: יציאה עכשיו, יציאה בשעה מסוימת או הגעה עד שעה מסוימת, עד 4 החלפות, חלופות (הגעה מוקדמת, פחות החלפות, פחות הליכה), ולוח יציאות לכל תחנה. הזמנים משוערים לפי לוח הזמנים של משרד התחבורה ([ADR 0007](docs/adr/0007-transit.md)).
- **קטגוריות מהירות**: מסעדות, בתי קפה, בתי כנסת, מקוואות, בתי מרקחת ועוד. בזום רחוק הסימונים מקובצים.
- **לחיצה ימנית / לחיצה ארוכה על המפה**: "מה יש כאן?", "מסלול מכאן/לכאן", "מה יש בסביבה".
- **המיקום שלי**, קישורים לשיתוף, היסטוריית חיפושים, ושימוש גם כאפליקציה מותקנת (PWA) במובייל.
- **נגישות לפי WCAG 2.1 AA**: מקלדת מלאה, קוראי מסך, ניגודיות, רשימה טקסטואלית של המקומות שבמפה, והצהרת נגישות.

## מבנה המערכת

```
דפדפן (HTML/CSS/JS, MapLibre GL)
      │  http://localhost:8080
      ▼
┌──────────────── api (Python/Starlette) ─────────────────┐
│ חיפוש עברי · נקודות עניין · גיאוקודינג · אריחי POI       │
│ מפת בסיס (MBTiles) · גופנים · דוחות · מדדים             │
└───────────┬─────────────────────────────┬───────────────┘
            │ SQLite: R*Tree + FTS5        │ HTTP / בתוך התהליך
            ▼                             ▼
        maps.db              ניווט: OSRM ×3 (Docker) או מנוע פנימי
   (נבנה ע"י etl)               רכב · הליכה · אופניים
            ▲
   etl: OpenStreetMap + data.gov.il + Wikidata/ויקיפדיה
   tiles: Planetiler ← OpenStreetMap  →  israel.mbtiles
```

| שירות | תפקיד |
|-------|-------|
| `api` | שרת האתר וה-API ([תיעוד API](docs/api.md)) |
| `routing` | שלושה שרתי OSRM, שמכינים את גרף הדרכים לבד בהפעלה הראשונה |
| `etl` (משימה) | איסוף, ניקוי, איחוד והעשרת נתונים ← `maps.db` + דוח איכות |
| `tiles` (משימה) | בניית מפת הבסיס הווקטורית (OpenMapTiles) |

ההחלטות הטכניות ונימוקיהן נמצאות ב-[docs/adr](docs/adr). מסמך המימוש המלא, כולל השוואה לתוכנית, מדידות ביצועים ומה נשאר: [docs/11-implementation.md](docs/11-implementation.md).

## פיתוח

```bash
pip install -r requirements-dev.txt
python -m playwright install chromium
python -m unittest tests.test_core tests.test_etl tests.test_api tests.test_router tests.test_native tests.test_terrain tests.test_icons
python -m unittest tests.e2e.test_ui                                # דפדפן, נגישות, סגנון מפה
python -m tests.perf_bench 120000                                   # ביצועים בקנה מידה ארצי
```

הרצת השרת מקומית על נתוני הדגמה:
```bash
python tools/sample_data.py data/sample-src
python -m hmaps.etl from-geojson --poi data/sample-src/poi.geojsonseq --streets data/sample-src/streets.geojsonseq --out data/maps.db
uvicorn hmaps.api.app:app --reload --port 8080
```
(לתצוגת המפה נדרשים קבצי `web/vendor/`. הם נוצרים אוטומטית בבניית Docker.)

האייקונים (PWA, מתקין ואפליקציית שולחן העבודה) נוצרים מקומית מקובץ המקור `web/icons/icon.svg`, ושום דבר לא מורד:
```bash
pip install -r requirements-icons.txt
python tools/make_icons.py          # --check: רק בדיקה שהקבצים מעודכנים
```

אפליקציית שולחן העבודה (`src-tauri/`, ‏Rust + Tauri 2) מול שרת פיתוח:
```bash
cd src-tauri && cargo build                         # Linux: libwebkit2gtk-4.1-dev libgtk-3-dev
HMAPS_URL=http://127.0.0.1:8080/desktop.html ./target/debug/hebrew-maps-desktop
```
(כתובת של `map.html` נפתחת אוטומטית בתוך `desktop.html`, כי לחלון אין מסגרת משלו. את מעטפת הלשוניות אפשר לפתוח גם בדפדפן רגיל: `http://localhost:8080/desktop.html`, בלי כפתורי החלון.)

CI: הקובץ `ci/github-actions.yml` מריץ את כל הבדיקות ובונה את האימג'. כדי להפעיל אותו ב-GitHub, מעתיקים אותו ל-`.github/workflows/ci.yml`.
‏`.github/workflows/weekly-data.yml` בונה ומפרסם את חבילות הנתונים השבועיות (ראו [עדכונים](#עדכונים) ו-[docs/12-operations.md](docs/12-operations.md)), ו-`.github/workflows/installer.yml` בונה את תוכנת ההתקנה.

```
hmaps/core   עברית (נרמול, תחיליות, קיצורים, תיקון שגיאות), קטגוריות, שעות פתיחה, גאומטריה, סכמה
hmaps/etl    צינור הנתונים: osmium → בנייה → העשרה → אינדקס חיפוש → דוח איכות
hmaps/api    API, מנוע חיפוש, אריחים וקטוריים, ניווט והוראות בעברית
hmaps/route  מנוע ניווט פנימי (גרף דרכים + A*), לשימוש בלי Docker
web/         ממשק המשתמש (ללא שלב build): js/, css/, sw.js, manifest
docker/      Dockerfile ושירות הניווט
src-tauri/   אפליקציית שולחן העבודה (Tauri 2): חלון, הפעלת השרת ועצירתו
installer/   PyInstaller + Inno Setup (מתקין Windows)
tests/       יחידה, אינטגרציה, דפדפן (Playwright), ביצועים
docs/        מסמכי הפרויקט + מימוש, החלטות, תפעול, API
```

## אתר ההורדה ופרסום גרסה

אתר המוצר וההורדה נמצא ב-`site/` (HTML ו-CSS סטטיים, בלי שלב build ובלי משאבים חיצוניים) ומתפרסם ב-GitHub Pages:
**https://rishumit.github.io/hebrew-maps/**. כפתורי ההורדה מצביעים על קישור קבוע,
`https://github.com/rishumit/hebrew-maps/releases/latest/download/HebrewMaps-Setup.exe`, שתמיד מוביל לגרסת האפליקציה האחרונה.
מספר הגרסה, הגודל והתאריך נטענים בדפדפן מ-`api.github.com`; אם הבקשה נחסמת (למשל בסינון), הכפתור עובד בכל זאת.

**הפעלה חד-פעמית של האתר:** ‏Settings ← Pages ← Build and deployment ← Source: **GitHub Actions**.
מכאן כל push ל-`main` שמשנה את `site/**` מפרסם את האתר (`.github/workflows/pages.yml`; אפשר גם להריץ ידנית מלשונית Actions ← "Product site (GitHub Pages)").
המאגר צריך להיות ציבורי, כדי שהאתר וקובצי ההתקנה יהיו נגישים לכולם.

**פרסום גרסת אפליקציה** (בונה את המתקין ויוצר Release שמסומן "Latest", עם `HebrewMaps-Setup-X.Y.Z.exe` ועם עותק בשם הקבוע `HebrewMaps-Setup.exe`):
```bash
git tag v1.2.0 && git push origin v1.2.0
```
או: Actions ← **Windows Installer** ← Run workflow, עם מספר גרסה ו-`release` מסומן.
חבילות הנתונים השבועיות (`data-*`) נוצרות עם `--latest=false`, כך שהן אף פעם לא תופסות את מקום "הגרסה האחרונה" של האפליקציה.
עד שמתפרסמת גרסת אפליקציה ראשונה, קישור ההורדה באתר מחזיר 404.

בדיקת האתר לפני push:
```bash
python tools/check_site.py site                    # קישורים, עוגנים, alt/width/height, כותרות
npx --yes html-validate site/*.html
cd site && python -m http.server 8000              # http://localhost:8000/
```
את תמונות האתר מצלמים מהאפליקציה עצמה, על נתוני ישראל המלאים (‏1440×900 ב-2x), ושומרים ב-`site/assets/img` כ-AVIF,‏ WebP ו-JPEG.
